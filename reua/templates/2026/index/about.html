{% trans "Про нас" %}

{% blocktrans %} Благодійний Фонд «Відбудуємо нашу Україну» (Rebuild Our Ukraine, REUA) — український фонд, заснований у травні 2022 року для підтримки відновлення та розвитку громад України. {% endblocktrans %}

{% blocktrans %} Фонд працює над розвитком децентралізованого водопостачання, підтримує критично важливі об’єкти та допомагає громадам залучати фінансування для вирішення нагальних інфраструктурних потреб. {% endblocktrans %}

{% blocktrans %} У своїй роботі REUA об’єднує зусилля міжнародних донорів, державних інституцій, бізнесу та місцевих громад, щоб перетворювати наявні ресурси й експертизу на практичні рішення. {% endblocktrans %}

{% trans "Наша місія" %}

{% blocktrans %} Сприяти відновленню та розвитку України, поєднуючи потреби громад із можливостями партнерів, експертизою та фінансовими ресурсами. {% endblocktrans %}

{% blocktrans %} Ми переконані, що ефективне відновлення починається з розуміння реальних потреб людей і потребує фахового підходу, відповідального планування та співпраці між різними секторами. {% endblocktrans %}

{% trans "Напрями діяльності" %}

  1. {% trans "Децентралізоване водопостачання" %}

    {% blocktrans %} ReH₂O — національна програма розвитку децентралізованої мережі постачання питної води в Україні. {% endblocktrans %}

    {% blocktrans %} Фонд розвиває мережу модульних станцій очищення води в медичних закладах і територіальних громадах. Вони забезпечують локальний доступ до безпечної питної води та доповнюють централізовані системи водопостачання, зокрема там, де їхня робота може бути порушена. {% endblocktrans %}

  2. {% trans "Підтримка критично важливої інфраструктури" %}

    {% blocktrans %} REUA реалізує проєкти, що допомагають забезпечувати безперебійну роботу важливих для громад об’єктів. {% endblocktrans %}

    {% blocktrans %} Один із напрямів — теплопостачання. Зокрема, фонд реалізував проєкт із передачі блочно-модульної котельні потужністю 2,8 МВт для потреб «Центру інноваційних технологій охорони здоров’я». {% endblocktrans %}

  3. {% trans "Залучення фінансування та інвестицій" %}

    {% blocktrans %} Фонд допомагає громадам знаходити фінансові можливості для реалізації інфраструктурних проєктів, які складно профінансувати власними силами. {% endblocktrans %}

    {% blocktrans %} REUA сприяє визначенню потенційних джерел фінансування, пошуку міжнародних донорів та інвесторів і налагодженню партнерств для залучення міжнародних ресурсів і приватного капіталу. {% endblocktrans %}

{% trans "Засновник і президент фонду"%}

{% blocktrans %} Олег Кленін — засновник і президент благодійного фонду «Відбудуємо нашу Україну», доктор економічних наук, професор. {% endblocktrans %}

{% blocktrans %} Має понад 30 років професійного досвіду в управлінні підприємствами та реалізації проєктів у промисловості, машинобудуванні, будівництві й енергетиці. Його досвід охоплює модернізацію виробничих потужностей, управління інвестиційними проєктами, розвиток систем водопостачання та водопідготовки, а також упровадження рішень з енергоефективності. {% endblocktrans %}

{% blocktrans %} Після початку повномасштабного вторгнення заснував REUA, щоб спрямувати свій професійний досвід на підтримку українських громад. {% endblocktrans %}
